# Lift — fitness app prototype (fake data)

A clickable **fake-data prototype** of the fitness app mockups. It is not the real app and has no backend: everything runs in the browser, and all workouts, history and progress are seeded demo data kept in `localStorage`.

**Open it:** https://jmoukel.github.io/fitness-prototype/

Apple Watch version: https://jmoukel.github.io/fitness-prototype/watch/ (shares the same demo data when opened on the same device)


## Using it on iPhone
- Open the link in Safari. For a full-screen, app-like view, tap Share → **Add to Home Screen**.
- Your changes (edits, logged sets, new plans) stay on that device.
- To start over, tap the plan name at the top (▾), then **Reset demo data**.

## What's in it
- Plan screen with this week's workouts and a "Done This Week" section
- Workout detail with "This Week's Target" (progressed values shown in the accent color)
- Edit mode: rename, icon, reorder, sets & reps, per-exercise progression rules, rest timer, delete
- Add Exercise sheet (search, muscle and equipment filters, favorites), exercise profiles, custom exercises with a photo
- Live workout: set logging, set editor, rest timer, finish & save
- New Plan and Build a Plan

"Lift" is a placeholder name. Plain HTML/CSS/JS with no build step.
